# SWIFT WHEELS - Rent-a-Car Management System

A console-based Rent-a-Car Management System developed in C for the IN1101 Programming Fundamentals course.

## Features

* Customer Management
* Vehicle Management
* Rental Processing
* Invoice Generation
* Administrative Logging

## Technologies Used

* C Programming Language
* Standard C Libraries

## How to Run

1. Clone the repository.
2. Compile the source code using a C compiler (GCC recommended).
3. Run the generated executable file.
